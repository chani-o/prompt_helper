프롬프트 도우미 Prompt Helper

구조화된 프롬프트 하나로 더 정확하고 완성도 높은 결과물을 만들어보세요.
💡 왜 구조화된 프롬프트가 더 좋은 결과를 만들까요?
❌ 자연어
"마케팅 전략 알려줘"
AI가 맥락 없이 일반적인 답변을 생성합니다. 역할·목적·대상이 불분명해 재질문이 필요한 경우가 많습니다.
✅ 구조화
역할 + 맥락 + 목표 + 형식
AI가 내 상황에 맞는 전문가 역할을 수행합니다. 재질문 없이 바로 활용 가능한 결과물을 생성합니다.
🔑 핵심 원칙
명확할수록 좋은 결과
역할(Role) · 과제(Task) · 맥락(Context) · 형식(Format)을 명시할수록 AI의 답변 완성도가 높아집니다.
이 도우미는 프롬프트 엔지니어링의 검증된 Best Practice(RTF, CO-STAR, SCQA 등)를 적용해 누구나 쉽게 구조화된 프롬프트를 만들 수 있도록 돕습니다.

✨ 구조화 프롬프트 패널 안내

ROLE · TASK · FORMAT
GUARD · COT 뱃지
프롬프트에 포함된 요소를 실시간으로 표시합니다. 흰색으로 활성화될수록 완성도 높은 프롬프트입니다. GUARD = 할루시네이션 방지, COT = 단계별 추론.
✏️ 편집 버튼
생성된 프롬프트를 직접 수정할 수 있습니다. 세부 조정이 필요할 때 활용하세요. "✅ 완료"를 누르면 수정된 내용이 복사에 반영됩니다.
📋 복사 버튼
프롬프트 창 우측 하단에 위치. 클릭 시 전체 프롬프트가 클립보드에 복사됩니다. 복사 후 "↗ 플랫폼에서 열기" 링크를 클릭하면 해당 AI 서비스로 바로 이동합니다.
프롬프트 탭
완성된 구조화 프롬프트를 확인합니다. 플랫폼별로 최적화된 문법이 자동 적용됩니다.
자연어 비교 탭
구조화 전(자연어)과 후(설계된 프롬프트)를 항목별로 비교합니다. 추가된 요소와 토큰 수 차이를 확인할 수 있습니다.
품질 분석 탭
프롬프트 완성도를 6가지 항목으로 점수화합니다. 미입력 항목을 확인하고 보완하세요.
💾 현재 설정 저장
현재 입력 내용을 이름 붙여 저장합니다 (브라우저 로컬, 최대 8개). 모달 하단에서 불러오기·삭제가 가능합니다.

👤 Step 2. AI 역할 설정

직군 선택
직무(인사, 개발 등) + 역할(기획, 운영 등)을 조합해 정밀한 역할을 설정합니다. 여러 개 중복 선택 가능.
조합 예시
인사 + 기획 → "인사 기획 전문가 입니다"
개발 + 운영 → "개발 운영 전문가 입니다"
직접 입력
특수한 역할은 자유 텍스트로 직접 작성 가능.
